# Validation & Testing

To validate Phase 8.4:

1. **Start Button Click**: Clicking the Start Button opens the menu.
2. **Outside Click**: Clicking the Desktop or Taskbar while the menu is open closes it.
3. **App Launch**: Clicking "Calculator" spawns the ATOMS Calculator window and closes the menu.
4. **Multitasking**: Open Terminal, Settings, and Calculator simultaneously.
5. **Dragging**: Dragging the top of the Terminal window moves it without smearing the pixels underneath.
6. **Focus**: Clicking Settings brings it above the Terminal window.
