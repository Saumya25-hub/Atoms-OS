## 4. Build Tooling & Dependency Mechanisms Discovered

1. **Meta-Build Generator (GN):**
   - File: `BUILD.gn` (54,477 bytes) and `.gn` (8,495 bytes).
   - Configures targets, toolchains, and arguments (`is_clang`, `is_debug`, `target_cpu = "x64"`, `target_os`).
2. **Build Executor (Ninja):**
   - High-speed parallel build tool executing native compile and link invocations generated by GN.
3. **Compiler & Linker:**
   - Host uses LLVM **Clang** (`clang++`) and **LLD** (`lld-link` or `ld.lld`) with `-std=c++20`.
4. **Dependency Specification (DEPS):**
   - File: `DEPS` (198,023 bytes). Tracks official revisions of sub-repositories (Blink, V8, Skia, BoringSSL, FreeType, HarfBuzz, ICU, dav1d).
5. **Python Build Scripting:**
   - Python 3.8+ scripts (`PRESUBMIT.py`, `tools/gn/`, Mojo IDL compiler). **Host-side build tool only; not required on ATOMS target.**

## 5. Supported Upstream Platforms in `build/config/`

The checkout natively supports these target OS configurations:
- `win/`: Microsoft Windows (Win32/UWP)
- `mac/`, `ios/`, `tvos/`: Apple Darwin platforms
- `linux/`: Standard GNU/Linux (X11/Wayland/Ozone)
- `android/`: Google Android (Bionic libc)
- `chromeos/`: ChromeOS (Ozone-GBM)
- `fuchsia/`: **Google Fuchsia (Modular microkernel OS — Golden Reference for ATOMS OS!)**
- `posix/`: General POSIX abstraction layer
- `aix/`, `zos/`: IBM enterprise UNIX/Mainframe

> [!TIP]
> **The Fuchsia Blueprint:** Google successfully ported Chromium to **Fuchsia** (a non-Linux, non-Windows microkernel). ATOMS OS can follow the exact architectural pattern used by Fuchsia (`base/fuchsia/`) to integrate cleanly without becoming a Linux derivative!
