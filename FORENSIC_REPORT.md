# FORENSIC_REPORT.md — 4X Horizontal Stride Division Bug Audit

## Executive Summary
This forensic report identifies the exact mathematical bug causing the login screen clock and icons to repeat 4 times horizontally in a top strip across the display.

---

## 1. Root Cause Findings

### Finding: Unconditional Stride Division by 4 (4X Wrap-Around)
- **Location**: [page_login.c](file:///d:/Signatures_OS/kernel/shell/rook/pages/page_login.c#L788)
- **Mathematical Bug**: `page_login_on_render` calculated: `uint32_t stride_pixels = stride / 4;`.
- **The Evidence**:
  - `stride` passed from `rook_render_flush` was already measured in pixels ($1920$).
  - Executing `1920 / 4` reduced `stride_pixels` to $480$ pixels per scanline.
  - Drawing into a $1920$-wide screen buffer with $480$-pixel stride caused scanlines to wrap 4 times faster ($1920 / 480 = 4$).
  - This mathematically compressed the Lock Screen Clock (`11:51`) and glass icons into the top $1/4\text{th}$ strip of the screen and repeated them **EXACTLY 4 TIMES HORIZONTALLY**, exactly as captured in the user's photo!

---

## 2. Permanent Fix Plan
- Update `stride_pixels` calculation in `page_login.c` to safely check if `stride` is in bytes ($\ge \text{width} \times 4$) or pixels:
  `uint32_t stride_pixels = (stride >= width * 4) ? (stride / 4) : ((stride > 0) ? stride : width);`
