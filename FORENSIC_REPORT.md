## 1. Root Cause Findings

### Finding: UEFI BIOS Memory Map Corruption via Direct MTRR MSR Write
- **Location**: [vram_accel.c](file:///d:/Signatures_OS/kernel/drivers/display/vram_accel.c#L77-L80)
- **Mechanism**: `wrmsr_safe(MSR_IA32_MTRR_PHYSBASE0, base_aligned | MTRR_TYPE_WRCOMB)` directly overwrites MTRR Variable Range Register Pair 0 (`0x200`).
- **Hardware Reality**: On physical Haswell / Raptor Lake motherboards, UEFI BIOS configures MTRR Pair 0 during POST to map lower System RAM. Overwriting `0x200` destroys System RAM caching rules, causing immediate CPU fault / black screen.
- **Resolution**: Remove direct MSR `0x200` MTRR writes. UEFI GOP framebuffer memory is already assigned optimal Write-Combining / Write-Through attributes by UEFI firmware.
