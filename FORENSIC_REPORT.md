# FORENSIC_REPORT.md — ATOMS OS Boot Splash Micro-Stutter Audit

## Executive Summary
This forensic investigation analyzes the root cause of remaining micro-stutter/jitter during the ATOMS OS Boot Splash sequence (`rook_splash_spin`) on physical bare-metal hardware (Haswell H81 and 14th Gen Intel Core i3-14100F + RTX 4060).

---

## 1. Root Cause Findings

### Finding A: Subsystem Interference & Background Thread Scheduling
- **Location**: [kernel.c](file:///d:/Signatures_OS/kernel/kernel.c#L453-L456)
- **Mechanism**: Before `rook_splash_spin(6000)` is invoked, 4 background system tasks (`ABDE_Telemetry`, `Heartbeat`, `Diagnostics`, `Debug_Shell`) are registered with the CPU scheduler.
- **Impact**: While `rook_splash_spin` renders frames on the main thread, the scheduler preempts the rendering loop to execute background tasks. Serial COM1 UART output and LAN UDP telemetry packets executed by these background tasks introduce CPU preemption delays (0.5ms to 3ms per context switch), resulting in uneven frame spacing.

### Finding B: Un-buffered Direct GOP VRAM Writes
- **Location**: [page_boot.c](file:///d:/Signatures_OS/kernel/shell/rook/pages/page_boot.c#L183-L209)
- **Mechanism**: `page_boot_on_render` draws dirty bounding box rects directly into physical VRAM over the PCIe bus without waiting for display beam vertical blanking (VSYNC).
- **Impact**: Mid-frame VRAM writes cause vertical scanline phase tearing, which appears as visual micro-stutter on physical high-resolution LCD monitors.

## 4. Risk Analysis
- High Risk: Modifying `kernel.c` task initialization order without strict plan can cause background tasks to fail if not resumed at Stage 2.
- Low Risk: Deferring background tasks until `ROOK_PAGE_LOGIN` ensures 100% CPU core isolation for Stage 1 Boot Splash.

---

## 5. Suspected Architecture Fix
- Defer/pause background system threads during Stage 1 (`DGL_STATE_BOOT`).
- Resume background system threads during Stage 2 (`DGL_STATE_LOGIN`).
- Isolate Stage 1 to 100% dedicated CPU rendering for guaranteed liquid-smooth motion.
