## 1. Root Cause Findings

### Finding: Single-Key Event Polling Limitation
- **Location**: [page_login.c](file:///d:/Signatures_OS/kernel/shell/rook/pages/page_login.c#L673)
- **Mechanism**: `page_login_on_update` polls a single keyboard event per frame iteration (`keyboard_poll_event(&key_evt)`).
- **Impact**: Rapid typing or key repeat events can be delayed if multiple scancodes accumulate in the keyboard ring buffer during frame updates.
- **Resolution**: Convert single-key polling into a full queue drain loop (`while (keyboard_poll_event(&key_evt))`) during `LOGIN_STATE_SIGN_IN`. This guarantees 100% zero-latency typing of password bullets and instant `Enter` key authentication.
