# FORENSIC_REPORT.md — PCIe Write-Combine Buffer Posting & LAN Debug Audit

## Executive Summary
This forensic report details the low-level PCIe x86 hardware mechanism causing UEFI BIOS text console memory artifacts (`====` lines and grey headers) to remain visible in VRAM during boot, and outlines the permanent PCIe memory barrier (`sfence`) fix under Protocol V1.

---

## 1. Root Cause Findings

### Finding A: Posted PCIe Write-Combining (WC) Stores Without Memory Barrier
- **Location**: [rook_render.c](file:///d:/Signatures_OS/kernel/shell/rook/src/rook_render.c#L118-L130)
- **Hardware Mechanism**:
  - Writes to GPU Framebuffer Base (`g_gop_fb`) on x86_64 CPUs execute through Write-Combining (WC) memory buffers.
  - Without an explicit `sfence` / `mfence` memory barrier after VRAM zeroing (`vram64[i] = 0`), CPU stores remain posted in WC queues and are NOT committed across the PCIe bus to physical VRAM.
  - Consequently, physical GPU VRAM (NVIDIA RTX 4060 / Haswell IGPU) retains the leftover UEFI BIOS POST text console buffer (`================` double lines, text lines, and grey headers).

### Finding B: Partial Dirty Rect Flushing During Boot Splash
- **Location**: [page_boot.c](file:///d:/Signatures_OS/kernel/shell/rook/pages/page_boot.c#L204)
- **Mechanism**: `page_boot_on_render` only invalidated the $70 \times 60$ spinner bounding box after Frame 0. Un-flushed WC buffers outside the spinner box allowed UEFI POST VRAM artifacts to persist.

---

## 2. Permanent Hardware Resolution Plan

### 1. Mandatory x86 PCIe Memory Barrier (`sfence` / `mfence`)
- Execute `__asm__ volatile("sfence" ::: "memory");` after VRAM zeroing in `rook_init_renderer` and after every `rook_render_flush` blit to force instantaneous PCIe bus commit.

### 2. Full Frame Repaint and Invalidation
- Force full frame redraws on `page_boot_on_render` and `page_login_on_render` so 100% of the $1920 \times 1080$ display is flushed to physical VRAM.

### 3. Activate UDP LAN Debug Telemetry
- Enable live UDP LAN Debug logging on port `9999` as requested by the user.
