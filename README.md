# ATOMS OS

A small hobby operating system built from scratch by a solo developer with AI assistance. It is not Windows 11 or Linux, and it is not production-ready. Just an independently built OS project developed step by step and continuously improved.

## Project

- **OS:** ATOMS OS
- **Kernel:** BOS Kernel
- **Filesystem:** BOFS
- **Development:** Solo developer + AI assistance
- **Status:** Hobby / experimental, continuously developing

ATOMS OS is built one step at a time, with the goal of learning, experimenting, building, testing, and improving an independent operating system.
